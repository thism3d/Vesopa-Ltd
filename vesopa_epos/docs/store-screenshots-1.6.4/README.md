## What is deliberately not here

- **The back office, the customer's phone and the card designer.** They are
  web pages, not this application, so they do not belong in a Windows Store
  listing for it. They are kept — moved to
  `Documents\Vesopa-Claude-Images\2026-09-05-store-release-1.6.4\not-for-store-browser-and-phone\`
  rather than deleted — because they are still the clearest picture of what the
  feature does for anyone writing about it.
- **The toast notification**, which is the headline of this release. It needs
  the till signed on and a live order arriving, and signing on needs a clerk
  PIN this session was not able to use. No picture was taken rather than a
  picture being claimed.
- **The lock switch** under Settings → Customer display, for the same reason it
  was missing in the first pass: the automation could not drive that page far
  enough on the day.
