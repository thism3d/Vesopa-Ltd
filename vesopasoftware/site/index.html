04 — How this happened

Nobody set out to build a payment network.

It started with a till that couldn't do what a landlord needed. Everything after that is consequence.

i

The problem

An old register on a bar, doing about a third of what the person behind it actually needed.

ii

The build

A prototype on a kitchen table, written against the way a real service night actually runs rather than a spec.

iii

First install

One venue, one terminal, one Friday night. It either takes money under pressure or it doesn't.

iv

Iteration

Version after version, shipped against what the floor asked for. The release notes are still public.

v

Going wider

Into the Microsoft Store, onto Mac, iPad and Android handhelds. The same till, wherever the work is.

vi

The stack closes

Hosting for the sites, then payments for the money. EPOS, Cloud and Pay, all ours end to end.
