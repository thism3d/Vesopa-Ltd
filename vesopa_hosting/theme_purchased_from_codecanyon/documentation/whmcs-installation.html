WHMCS templates installation

We are giving only Child Theme of WHMCS's default template twenty-one. We did not change anything except the design and some custom hooks for design purpose.

Prerequisites:

  • You should have installed WHMCS on your server. Please check the WHMCS Official Documentation .
  • Check that your installed WHMCS is working with a default template like `twenty-one`.

Then follow our documentation's instructions to install our WHMCS template.

How to install the WHMCS templates?

We have designed the WHMCS template and orderform. you need to follow the below steps to complete the template installation completely:

  1. Add your WHMCS template - Localhost to the templates folder
  2. Add the `localhost_cart` orderform to the orderforms folder
  3. Add hooks files to the hooks folder
  4. Configure your price from the WHMCS admin panel
  5. Change the default WHMCS template and orderform from the admin panel

Add Templates Folder

Add your WHMCS template "localhost" to the templates folder.

  • Go to the path: /<your-public-root-directory>/whmcs/templates
  • Unzip your uploaded template/file if you have the zip version
  • You will see the template folder name like - localhost
  • View this screenshot as an example:

Add Templates Folder

Add the "localhost_cart" orderform to the orderforms folder

  • Go to the path: /<your-public-root-directory>/whmcs/templates/orderforms
  • Unzip the "localhost_cart" orderform folder if you have the zip version
  • Add the "localhost_cart" folder

How to Update Language

Add overrides folder to the lang folder:

  • Go to the path: /<your-public-root-directory>/whmcs/templates/lang/override
  • Upload the override folder to your lang folder. In this override folder we have included english.php file. This english.php & arabic.php file is overrided and added all new variables for our template
