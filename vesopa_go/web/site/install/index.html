Vesopa Go 1.2.59: test build

Version 1.2.59 (2)

For Vesopa's registered test iPhones only. It carries Tap to Pay on iPhone for testing before Apple approves the app for the App Store.

Install on this iPhone

  1. Open this page in Safari on the iPhone and tap Install on this iPhone, then Install.
  2. It replaces the TestFlight copy of Vesopa Go. Sign in again afterwards.
  3. If it says the app cannot be opened: Settings > Privacy & Security > Developer Mode, turn it on and restart the iPhone.
