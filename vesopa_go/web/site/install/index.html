Vesopa Go: test builds

iPhone

Version 1.2.61 (1)

For Vesopa's registered test iPhones only. It carries Tap to Pay on iPhone for testing before Apple approves the app for the App Store.

Install on this iPhone

  1. Open this page in Safari on the iPhone and tap Install on this iPhone, then Install.
  2. It replaces the TestFlight copy of Vesopa Go. Sign in again afterwards.
  3. If it says the app cannot be opened: Settings > Privacy & Security > Developer Mode, turn it on and restart the iPhone.

Android

Version 1.2.61 (63)

The same app as Google Play's test track, as a file to install straight from this page.

Download for Android

  1. If Vesopa Go from Google Play is on the phone, uninstall it first: the two are signed differently and Android will not put one over the other. Sign in again afterwards.
  2. Open this page in Chrome on the phone, tap Download for Android, then open the file.
  3. If Android asks, allow Chrome to install unknown apps, then tap Install.
