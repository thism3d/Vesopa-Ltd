Connect a screen

This is the code on your new screen or TV:

 

With Vesopa Go

  1. On a phone or tablet that is already signed in to your venue, open Vesopa Go.
  2. Go to Settings, then Connect a screen or TV.
  3. Scan the code on the screen with it, or type the code above.
  4. Choose what the screen is for: a customer display, a kitchen screen, a till or a card terminal.

With the back office

  1. Sign in at backoffice.vesopaepos.com.
  2. Open Devices and find Terminals.
  3. Type the code under Connect a screen or TV by its code and press Connect.

A code lasts ten minutes. The screen shows a new one by itself when it runs out.
