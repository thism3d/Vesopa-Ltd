With Vesopa Go

On a phone or tablet with Vesopa Go signed in to your venue, scanning the screen's code with the camera opens Vesopa Go straight at Connect this screen. If you are reading this page, Vesopa Go is not on this device yet:

Get Vesopa Go How it works

  1. Sign in to your venue in Vesopa Go.
  2. Scan the code on the screen again with the camera, or in Vesopa Go: Settings, Connect a screen or TV.
  3. Choose what the screen is for: a customer display, a kitchen screen, a till or a card terminal.

With the back office

  1. Sign in at backoffice.vesopaepos.com.
  2. Open Devices and find Terminals.
  3. Type the code under Connect a screen or TV by its code and press Connect.

A code lasts ten minutes. The screen shows a new one by itself when it runs out.
